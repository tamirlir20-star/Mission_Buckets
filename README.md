# לוח משימות - פרויקט המשחק

אתר קנבן פשוט לניהול משימות משותף לקבוצת חברים שעובדים על פיתוח משחק. בלי סיסמאות — כל אחד בוחר שם בכניסה.

## הרצה מקומית (פיתוח)

מהתיקייה הראשית:

```
npm install
npm run dev
```

זה מריץ במקביל שרת Express על `http://localhost:3001` ולקוח Vite על `http://localhost:5173`. פתחו את `http://localhost:5173` בדפדפן. בפיתוח מקומי אין צורך בשום חשבון חיצוני — הנתונים נשמרים בקובץ `server/data.sqlite`.

### גישה לחברים דרך הרשת המקומית (בלי אינטרנט)

מצאו את כתובת ה-IP המקומית שלכם (`ipconfig`, שדה "IPv4 Address") והחברים יגשו ל-`http://<ה-IP-שלכם>:5173` כשהם באותה רשת.

## פריסה לאינטרנט (חינמי לגמרי)

כדי שהחברים יתחברו מכל מקום, בלי שהמחשב שלכם צריך להיות דלוק, פורסים לשירותים חינמיים:

- **Turso** — בסיס נתונים SQLite מנוהל בענן (חינמי, בלי כרטיס אשראי) ששומר את הנתונים לצמיתות.
- **Render** — מארח את השרת (חינמי). האתר "נרדם" אחרי כ-15 דקות ללא שימוש, וההתעוררות הבאה לוקחת כ-20-50 שניות.

### שלב 1: יצירת בסיס נתונים ב-Turso

1. הירשמו ב-[turso.tech](https://turso.tech) (אפשר עם חשבון GitHub).
2. צרו בסיס נתונים חדש (בדשבורד: Create Database, למשל בשם `game-tasks`).
3. מהדשבורד של בסיס הנתונים, העתיקו:
   - את ה-**Database URL** (מתחיל ב-`libsql://...`)
   - צרו **Auth Token** חדש והעתיקו אותו
4. שמרו את שני הערכים בצד — נזדקק להם בשלב הבא.

### שלב 2: פריסה ל-Render

1. הירשמו ב-[render.com](https://render.com) (אפשר עם חשבון GitHub — זה גם ייתן ל-Render גישה ל-repo).
2. לחצו **New > Blueprint**, ובחרו את ה-repository. Render יזהה אוטומטית את קובץ `render.yaml` שבשורש הפרויקט ויציע שירות בשם `game-task-board`.
3. כשמתבקשים, הדביקו את `TURSO_DATABASE_URL` ו-`TURSO_AUTH_TOKEN` מהשלב הקודם.
4. אשרו את היצירה. אחרי כמה דקות תקבלו כתובת ציבורית בסגנון `https://game-task-board.onrender.com` — זו הכתובת שתשתפו עם החברים.

מכאן, כל `git push` ל-branch הראשי יגרום ל-Render לבנות ולפרוס גרסה חדשה אוטומטית.

## טכנולוגיה

- **שרת**: Express + TypeScript. הגישה לנתונים דרך `@libsql/client` — באופן מקומי זה קובץ SQLite רגיל (`server/data.sqlite`), ובפריסה זה מצביע לבסיס הנתונים ב-Turso (משתני הסביבה `TURSO_DATABASE_URL` / `TURSO_AUTH_TOKEN`), אותו קוד בדיוק בשני המקרים.
- **לקוח**: React + Vite + TypeScript, גרירה בין עמודות עם `@dnd-kit`, ורענון אוטומטי (polling כל 4 שניות) כדי לראות עדכונים של חברים אחרים.

## מבנה

```
/server       - Express API + SQLite/Turso
/client       - React + Vite (לוח הקנבן)
render.yaml   - הגדרת פריסה ל-Render
```
