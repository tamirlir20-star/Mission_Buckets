# לוח משימות - פרויקט המשחק

אתר קנבן פשוט לניהול משימות משותף לקבוצת חברים שעובדים על פיתוח משחק. בלי סיסמאות — כל אחד בוחר שם בכניסה.

## הרצה (פיתוח, מקומי)

מהתיקייה הראשית:

```
npm install
npm run dev
```

זה מריץ במקביל:
- שרת Express על `http://localhost:3001`
- לקוח Vite על `http://localhost:5173`

פתחו את `http://localhost:5173` בדפדפן.

### גישה לחברים דרך הרשת המקומית

מצאו את כתובת ה-IP המקומית שלכם (למשל עם `ipconfig` וחפשו "IPv4 Address"), ואז החברים יגשו ל-`http://<ה-IP-שלכם>:5173` כשהם באותה רשת Wi-Fi. שני השרתים מאזינים על `0.0.0.0` כך שהם נגישים גם ממכשירים אחרים באותה רשת.

הערה: הגישה זמינה רק כשהמחשב שרץ עליו האתר דלוק והשרת פועל.

## הרצה כ"פרודקשן" מקומי (שרת אחד בלבד)

```
npm run build
npm start
```

זה בונה את הלקוח ומגיש הכל דרך שרת ה-Express היחיד על פורט 3001 (`http://localhost:3001`, ונגיש גם דרך ה-IP המקומי).

## טכנולוגיה

- **שרת**: Express + TypeScript, נתונים נשמרים ב-SQLite (`server/data.sqlite`) דרך המודול המובנה `node:sqlite` של Node — אין תלות בכלי build נייטיביים.
- **לקוח**: React + Vite + TypeScript, גרירה בין עמודות עם `@dnd-kit`, ורענון אוטומטי (polling כל 4 שניות) כדי לראות עדכונים של חברים אחרים.

## מבנה

```
/server   - Express API + SQLite
/client   - React + Vite (לוח הקנבן)
```
